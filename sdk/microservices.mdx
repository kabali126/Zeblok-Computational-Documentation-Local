A microservice is a running deployment started from a catalog template. Registering the
templates themselves is [Imports › Microservices](/sdk/ms-import).

In the web interface: **Workspace → Microservices**.

## Capabilities

| What you want to do | SDK call | API |
|---|---|---|
| Deploy one | `client.microservices.spawn(...)` | `POST /api/v1/spawned-services` |
| List running | `client.microservices.spawned()` | `GET /api/v1/spawned-services` |
| Pod name → id | `client.microservices.get_spawned_id_by_name(pod)` | `GET /api/v1/spawned-services` |
| Replica counts | `handle.replica_status()` | `GET /api/v1/spawned-services/replica-status/:id` |
| Stop, resize, share, delete | See [Workload lifecycle](/sdk/lifecycle) | — |
| CPU, memory, disk | See [Monitoring](/sdk/monitoring) | — |

## Deploy

<Frame caption="Omit ports/envs and the template's defaults are used, exactly as the web interface pre-fills them.">
  <img src="/images/sdk/microservices/deploy-with-template-defaults.png" alt="Deploying a microservice that inherits the template's ports and envs" />
</Frame>

```python
ms = client.microservices.get_by_id(MICROSERVICE_ID, print_stdout=False)

pod_name, url = client.microservices.spawn(
    display_name=ms["display_names"][0],
    microservice_id=MICROSERVICE_ID,
    plan_id=PLAN_ID,
    microservice_name="orders-api",       # unique, lowercase
    namespace_id=NAMESPACE_ID,

    # ports=[{"protocol": "HTTP", "portIdentifier": "http", "number": 8080}],
    # envs=[{"key": "LOG_LEVEL", "value": "debug"}],
)
```

<Warning>
  `spawn()` hands back the Kubernetes **pod name**, not the database id. Convert it before
  managing the service — a pod name produces `400 Validation failed`.
</Warning>

## Find it, and get its URLs

```python
svc_id = client.microservices.get_spawned_id_by_name(pod_name)
handle = client.spawned("service", svc_id)

print("open at:", handle.open_url())
print("call it from inside the cluster at:", handle.internal_url())
print("replicas:", handle.replica_status())
```

<Note>
  Use the **internal** address for service-to-service calls — it stays inside the cluster,
  which is faster and does not depend on the public route.
</Note>

## Start several at once

```python
from zeblok.batch import unique_names, batch

names = unique_names("orders-api", 2, existing=client.microservices.spawned)

result = batch(names, lambda n: client.microservices.spawn(
    display_name=ms["display_names"][0],
    microservice_id=MICROSERVICE_ID,
    plan_id=PLAN_ID,
    microservice_name=n,
    namespace_id=NAMESPACE_ID,
))

print(result.summary())
```
