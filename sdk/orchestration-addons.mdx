An add-on is a running cluster tool started from a catalog template. Registering the templates
themselves is [Imports › Orchestration Add-ons](/sdk/oa-import).

In the web interface: **Workspace → Orchestration Add-on**.

## Capabilities

| What you want to do | SDK call | API |
|---|---|---|
| Deploy one | `client.orchestrations.spawn(...)` | `POST /api/v1/spawned-k8s-addons` |
| List running | `client.orchestrations.spawned()` | `GET /api/v1/spawned-k8s-addons` |
| Pod name → id | `client.orchestrations.get_spawned_id_by_name(pod)` | `GET /api/v1/spawned-k8s-addons` |
| Change the worker range | `handle.reconfigure(...)` | `PUT /api/v1/spawned-k8s-addons/:id/reconfigure` |
| Stop, share, delete | See [Workload lifecycle](/sdk/lifecycle) | — |

## Deploy a cluster

<Frame caption="Add-ons take min_workers / max_workers instead of a display name — the one place their spawn differs from micro-services and workstations.">
  <img src="/images/sdk/orchestration-addons/spawn-addon.png" alt="Deploying a Ray cluster add-on with a worker range" />
</Frame>

```python
catalog  = client.orchestrations.get_all(print_stdout=False)
ADDON_ID = catalog[0]["id"]

client.orchestrations.spawn(
    orchestration_id=ADDON_ID,
    plan_id=PLAN_ID,
    namespace_id=NAMESPACE_ID,
    orchestration_name="my-ray-cluster",
    min_workers=1,
    max_workers=3,
)
```

## Change the worker range

```python
running = client.orchestrations.spawned()
handle  = client.spawned("addon", running[0]["_id"])

handle.reconfigure(min_workers=2, max_workers=5)      # grow the cluster
```

<Warning>
  **Add-ons take no `plan_id` when reconfiguring.** They use `head_plan_id` and
  `worker_plan_id`, because the head node and the workers can be different sizes. Passing
  `plan_id` is refused with the allowed list.

  There is also no `edit()` route for add-ons — `reconfigure()` is how you change them.
</Warning>

## Start several at once

```python
from zeblok.batch import unique_names, batch

names = unique_names("ray-cluster", 2, existing=client.orchestrations.spawned)

result = batch(names, lambda n: client.orchestrations.spawn(
    orchestration_id=ADDON_ID,
    plan_id=PLAN_ID,
    namespace_id=NAMESPACE_ID,
    orchestration_name=n,
    min_workers=1, max_workers=2,
))

print(result.summary())
```
